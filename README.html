Agent Skill · 使用说明

AI 非录音笔文本总结

把录音转写、课程讲稿、口播文案，直接变成单文件 HTML 总结网页：零外部依赖、明暗双主题、移动端安全网内置。支持自定义主题色，不指定则默认原始微信绿色系。一份目录可在 WorkBuddy / Claude / Cursor / Codex / DeepSeek 多平台安装。本页由该 skill 以科技蓝 #2563eb生成，即效果预览。

声明：此 skill 是基于对微信 AI 录音笔进行反编译分析后编写的，仅供学习参考之用。

01theme_tokens.py主题色脚本：一个 accent 派生明暗双套设计令牌
02base-template.html页面骨架：安全网 + 组件库 + 动效脚本，唯一占位符
03pipeline.md管线契约：页面结构、组件规范、图表元数据、内容规则
第一部分 · 它解决什么问题
定位

从口语转写，到一读即懂的网页

传统 AI 总结输出 Markdown 或纯文本，阅读成本高、分享体验差。本 skill 让模型直接输出完整 HTML 页面：结构契约固定、色板令牌化、移动端安全网兜底，任何产出版式统一，可直接 iframe 嵌入分享。

三个硬保证：零外部依赖（无 CDN、无外链字体与图片，图形全部内联 SVG/CSS 绘制）；760px 居中，任何窄屏不出现横向滚动；明色 / 暗色 / ≤600px 窄屏 / 减少动效四类适配默认全覆盖。

未指定主题色时，一律使用默认预设（原始微信绿色系），不要询问、不要发明新配色。
洞察管线的核心是解耦：版式稳定性交给固定 CSS 契约（安全网 + 组件库），内容创作交给模型，颜色交给一个参数。换主题只换令牌块，内容与结构不动。
第二部分 · 主题色系统
核心扩展

一个色，派生一整套令牌

用户给颜色名（"科技感一点"）、十六进制（"#2563eb"）或场景词均可，脚本按固定规则派生明暗两套令牌，禁止手推色值。常用映射：科技感 = 蓝、暖色 = 橙红、金融 = 金、自然 = 绿。

换主题只需重跑脚本、替换令牌块，内容不动。
洞察on-accent 按亮度自动切深/浅文字，亮色主题不会出现低对比度白字；warn 警示家族是语义色，不随主题变化。

两条红线

安全网 CSS 禁止改动一个字符；主题色必须走 theme_tokens.py，禁止手推色值。

违反任一条即破版或失真——安全网是窄屏不横向滚动的唯一保障。

生成一页的四步清单

    定主题色

    套骨架

    复制 base-template.html，用脚本输出替换 /*__THEME_TOKENS__*/ 占位符。

  3. 3
    填内容

    按 pipeline.md 契约写 hero、分区、模块、图表与落款。

  4. 4
    过校验

    六项检查全过再交付，每张图带全 5 个 data-visual-* 属性。
